# Local fonts

Latin variable WOFF2 files downloaded from Google Fonts on 27 November 2026.
They are bundled so production builds do not depend on a Google Fonts network
request. Geist is preloaded; Geist Mono and Playfair Display load only when used.
All three retain `font-display: swap` through `next/font/local`.

- Geist: https://fonts.gstatic.com/s/geist/v5/gyByhwUxId8gMEwcGFU.woff2
- Geist Mono: https://fonts.gstatic.com/s/geistmono/v6/or3nQ6H-1_WfwkMZI_qYFrcdmg.woff2
- Playfair Display: https://fonts.gstatic.com/s/playfairdisplay/v40/nuFiD-vYSZviVYUb_rj3ij__anPXDTzYgA.woff2

Each font's SIL Open Font License is stored beside it. Licenses originate from
the corresponding `ofl` directories of https://github.com/google/fonts.
